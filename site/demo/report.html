critical PHP2Shell CVE-2026-109618CVE-2026-109619 CVSS 4.0 · 9.2 published发布于 2026-10-21

Two memory-safety flaws in the PHP engine let an unauthenticated HTTP request corrupt request state (through out-of-memory bailouts) or reuse freed global state in a later request on the same worker, leading to remote code execution as the web worker account. Apache mod_php is confirmed exploitable; PHP-FPM, FrankenPHP and LiteSpeed are considered likely susceptible.PHP 引擎中的两个内存安全缺陷：未授权的 HTTP 请求可以借助内存耗尽时的异常退出破坏请求状态，或让同一工作进程的后续请求复用已释放的全局状态，最终以 Web 进程账号的权限执行任意代码。Apache mod_php 已被证实可利用，PHP-FPM、FrankenPHP 和 LiteSpeed 被认为同样可能受影响。

How to read this report如何阅读本报告

Bastion only reads files and process metadata; it changed nothing on this machine. Fixed means a fixed upstream version, a vendor package at or above the vendor's fixed version, a package changelog naming the CVE, or code that only the fix introduces. Likely vulnerable means a build Bastion cannot prove patched (for example an end-of-life branch or a package whose changelog is silent). Unknown means there was not enough information — ask the vendor. Trace findings are indicators, not proof; a clean trace does not prove a clean system.

Bastion 只读取文件和进程信息，没有改动这台机器上的任何东西。已修复表示：上游版本已修复、发行版软件包不低于官方给出的修复版本、软件包变更日志中写明了该 CVE，或者二进制中含有只有补丁才会引入的代码。很可能存在漏洞表示 Bastion 无法证明它已打补丁（例如已停止维护的分支，或变更日志中没有任何记录的软件包）。无法判断表示信息不足，请向供应商确认。溯源结果只是线索而非定论；没有发现问题也不代表系统一定干净。
