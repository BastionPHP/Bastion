How to read this report

Bastion only reads files and process metadata; it changed nothing on this machine. Fixed means a fixed upstream version, a vendor package at or above the vendor's fixed version, a dated vendor rebuild, a package changelog naming the CVE, or code only the fix contains. Likely vulnerable means a build Bastion cannot prove patched, for example an end-of-life branch or a package whose vendor database or changelog is silent. Unknown means there was not enough information; ask the vendor. Trace findings are indicators, not proof, and a clean trace does not prove a clean system.
