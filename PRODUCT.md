# Bastion product context

## Register

brand

## Users

Server operators and incident responders assessing PHP installations, patches, and intrusion indicators. They need readable evidence and direct access to commands and documentation.

## Product Purpose

Explain Bastion's local assessment workflow and let visitors inspect recorded output, try the browser check, and find the command reference.

## Brand Personality

Precise, restrained, trustworthy. Preserve the existing technical-manual identity.

## Anti-references

The user explicitly requested retaining the current style and refining details only. Avoid a new visual identity, decorative dashboard cards, marketing metrics, or dramatic animations.

## Design Principles

- Preserve the existing steel-blue palette, typography, artwork, and page structure.
- Improve hierarchy through spacing, alignment, and readable contrast.
- Keep status colors tied to assessment meaning.
- Show real recorded evidence and keep uncertainty explicit.
- Make mouse, keyboard, and mobile interactions equally usable.

## Accessibility & Inclusion

Retain light and dark themes, reduced-motion support, semantic controls, and visible keyboard focus. Check text contrast and narrow-screen layouts during refinements.
